# Стресс-тестирование модифицированной структуры данных — `ShardedHashTable`

## Использованные классы

- **`HashTable`** — однопоточная хеш-таблица, в которой коллизии разрешаются с помощью бинарного дерева поиска (BST). Поддерживает операции `get`, `set` и итерацию.
- **`ShardedHashTable`** — многопроцессная версия, реализованная с использованием `multiprocessing`. Данные распределены по `N` шардам (сегментам), каждый из которых обрабатывается в отдельном процессе. Для обеспечения корректности при параллельном доступе используется механизм атомарных операций через очереди и блокировки на уровне шарда.

## Цель эксперимента

Провести стресс-тестирование `ShardedHashTable` на соответствие следующим требованиям:
- Выполнение **более 5 000 000 операций**;
- **Не менее 75% операций — чтение (`get`)**;
- Обеспечение **целостности данных** при одновременном доступе;
- Отсутствие ошибок, дедлоков или потерь данных.

## Методология тестирования

Тест выполнялся с использованием сценария:
- **4 потока** генерировали операции случайным образом;
- **80% операций — чтение (`get`)**, **20% — атомарное обновление (`atomic_update`)** с инкрементом;
- **10 000 уникальных ключей**, равномерно распределённых;
- Обе версии (`HashTable` и `ShardedHashTable`) тестировались на одинаковом наборе данных;
- Для запуска использовался скрипт `examples/hw6/run_example.py`;

## Результаты

| Версия | Время выполнения | Пропускная способность | Ошибки |
|--------|------------------|------------------------|--------|
| `HashTable` | **10.44 с** | **479 034 ops/sec** | 0 |
| `ShardedHashTable` | **425.19 с** | **11 759 ops/sec** | 0 |

## Вывод

Результаты стресстеста и базовых тестов подтверждают, что `ShardedHashTable` **корректно обеспечивает потокобезопасность** и **не допускает потерь данных** при высокой нагрузке. Однако, как и ожидалось, **производительность снижается в ~40 раз** по сравнению с однопоточной версией. Это обусловлено **накладными расходами на межпроцессное взаимодействие**: сериализация запросов, передача через очередь, ожидание ответа и синхронизация.
